# 骑行路线设计器 · 环法坡度分级

基于地图的自行车路线设计工具:点击地图添加途经点,自动规划骑行路线,实时分析高程,
并按**环法爬坡分级标准**(HC / 1 / 2 / 3 / 4 级)标注每一段爬坡。

## 启动

```bash
python server.py          # 默认 8765 端口
# 浏览器打开 http://127.0.0.1:8765
```

> 请通过 `server.py` 访问,不要直接双击 index.html —— 高程数据需要通过本地代理获取(CORS 限制)。
> 仅使用 Python 标准库,无需安装任何依赖。

## 功能

| 功能 | 说明 |
|---|---|
| 地址搜索 | 地图顶部搜索框:输入地点回车,点击结果自动添加为途经点并定位(引擎:高德Key → Photon(OSM,免Key) → Nominatim) |
| 路线规划 | 单击地图追加途经点,拖动编号圆点调整;双击缩放 |
| 高程分析 | 总爬升/总下降、高程剖面图(按坡度着色,悬停查看任意点坡度) |
| 环法分级 | 自动识别爬坡段,按 HC/1/2/3/4 级标注图标、色带与清单 |
| 坡度渲染 | 路线按每段坡度着色(绿=平路 → 黄/橙/红 → 紫=≥9%) |
| GPX 导出 | 一键导出含高程的 GPX 文件(WGS84 坐标,可导入码表/骑行 App) |
| 状态保存 | 途经点、引擎、Key、地图位置自动保存在浏览器本地 |

## 路线引擎(自动选择,可手动指定)

1. **BRouter(OSM 路网)** —— 首选。基于 OpenStreetMap 骑行路网 + SRTM 高程,
   支持 休闲/公路/快速/最短 四种骑行风格。需要能访问国际网络(部分网络环境不稳定)。
2. **高德骑行 API** —— 国内网络首选,需免费 Key:
   在[高德开放平台](https://console.amap.com/dev/key/app)创建应用,
   Key 类型选「**Web服务**」,粘贴到页面输入框即可。坐标系已自动做 GCJ-02→WGS84 转换。
3. **直线手绘** —— 兜底方案。途经点间为直线,仍通过 SRTM 30m 高程数据分析坡度与分级。

## 底图(右上角图层控制切换)

| 图层 | 坐标系 | 说明 |
|---|---|---|
| OSM 标准 | WGS84 | OpenStreetMap 官方(需国际网络) |
| CyclOSM 骑行图 | WGS84 | 骑行要素增强的 OSM 风格(需国际网络) |
| OpenTopoMap 地形 | WGS84 | 带等高线的地形图(需国际网络) |
| Esri 卫星影像 | WGS84 | 高分辨率全球影像,看路况/地形很直观 |
| 高德地图 / 高德卫星 | GCJ-02 | 国内源,自动偏移已处理 |
| 腾讯地图 | GCJ-02 | 国内源 |
| 天地图 矢量 / 影像 | WGS84 | 国家官方图源,需在下方输入框填入[天地图 Key](https://console.tianditu.gov.cn/api/key)(免费申请) |

叠加层(可与底图叠加显示):**骑线路网 / 徒步路网**(Waymarked Trails,基于 OSM 的长途骑行/徒步路网)。
注意:叠加层为 WGS84 坐标,与高德/腾讯底图叠加会偏差几百米,建议配合 OSM/Esri/天地图使用。

> 启动时自动探测网络并选择默认底图;GCJ-02 底图(高德/腾讯)下路线/途经点坐标已自动换算对齐。

## 环法爬坡分级规则(估算)

官方分级由赛事裁判综合坡长×坡度×海拔判定,无公开公式。本工具采用通行估算:

| 级别 | 判定 |
|---|---|
| 4 级 | 爬升约 60–150 m |
| 3 级 | 爬升 150–350 m |
| 2 级 | 爬升 350–650 m |
| 1 级 | 爬升 650–1000 m |
| HC | 爬升 > 1000 m |

平均坡度 ≥8–9% 或最大坡度 ≥13% 时升一级;爬升不足 60 m 的小坡标记为「未分级」。
